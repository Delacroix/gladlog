# Prompt 逐行效果探针:结果(2026-08-26)

> 方法与八个坑见 [2026-08-24-prompt-line-probe-method.md](2026-08-24-prompt-line-probe-method.md)。
> 本文只记结果。数据:100 局钉死快照(S2 归档),消融有效样本 4,986(agy 3,200 全量 28 类 /
> sonnet 600 全量 13 类 / haiku 1,186 中途下马留档),植入 200(agy,100 局 × 2)。

## 消融:零显著

| run | 有效样本 | 噪声底(基线自比 Jaccard) | 显著类型(|z|≥2) |
|---|---:|---|---|
| agy | 3,200 | 0.735 ± 0.225(n=300 对) | **无**(最强 [CC ON TEAM] −0.047,z=−1.8) |
| sonnet | 600 | 0.688 ± 0.175(n=40) | 无(最强 [RES] z=−1.1) |
| haiku | 1,186 | 0.583 ± 0.191(n=79) | 无;2026-08-25 用户裁定下马(噪声太大) |

跨模型效应排序 Spearman:agy×sonnet **0.35** / agy×haiku 0.28 / sonnet×haiku 0.12(13 共同类型)。

**读法**:删掉任何一类行 —— 含 16.5% 字符的 `[STATE]` —— 各模型结论主题不变;三家对
「谁稍微重要」的排序互不认账。结论主题由冗余信息决定,「加行/删行」层面的 prompt 优化
低于一切后端的噪声底。噪声底阶梯本身(0.735/0.688/0.583)是另一半结论:**同 prompt 两跑
主题只 58–74% 重合,后端选型对一致性的影响压过一切 prompt 微调。**

## 植入:判词被静默接受,矛盾从不被指出

每局掉血最狠的 `[DMG SPIKE]`(掉幅中位 53pp)结论词反转成 `healed through`(与同 prompt
的 `[STATE]` 直接矛盾):基线讨论该时刻 90/100;植入后仍讨论 92%;**极性翻转仅 5/90(6%)**;
**显式指出矛盾 0/100**。单局轶事(DeepSeek 被同一操作从「打得完美」翻转成「恐慌交」)
不能外推 —— 翻转率是模型相关的;但「从不指出矛盾」在两个模型上一致。

**读法**:冗余证据通常兜得住一句谎话,但 prompt 内部一致性没有任何模型侧防线 ——
promptQualityCheck 的确定性 hardFailures 是唯一防线,本实验验证了该设计的必要性。

## 可执行建议

1. 停止行类型级增删优化(测不出收益);
2. 逐句审计判断词,植入探针作措辞回归测试;
3. 一致性先选后端再谈 prompt(agy > sonnet > haiku);
4. 补模型点名要的事实(伤害可减性 / spike 预警 / spike 期间敌方控制掩护 —— 第三样有现成数据),过价值门再上;
5. 新判断词进 prompt 应配对应的确定性门。

## 局限

跨版本混采(偏向假阳性,而结果仍零显著 → 强化空结论)/ 主题粒度指标 / CLI 无温度控制 /
治疗视角语料 / 植入单类型单谎话 / 追问 n=1。完整 caveat 与额度节奏见方法文档与
报告 artifact(2026-08-26 发布)。

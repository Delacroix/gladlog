# Parser M4: Compat Adaptation Layer + Differential Testing — Implementation Plan

> Working method same as before: contract = written by controller; implementation = agy exec; strictly forbidden from reading legacy parser source code. **Enum values source = `packages/parser-compat/data/legacy-enum-manifest.json`** (runtime values dumped by privately executing the old package in the old repository, constituting interoperability facts; dump script located in old fork `scratch/parser-diff/dumpEnums.ts`). Key fact: `CombatUnitClass` / `Reaction` / `Type` / `Result` are numeric enums whose ordering differs from official Blizzard enums (1=Warrior, 2=Hunter…); they must be aligned value-by-value against the manifest, not written based on common intuition.

## Tasks

1. **Compat Package Skeleton + Enums**: `packages/parser-compat` (`package.json` / `tsconfig` following parser pattern, depends on `@gladlog/parser`). `src/enums.ts` statically defines all 7 enums according to manifest (TS enum: `LogEvent` / `CombatUnitSpec` are string enums, remainder are numeric enums). Tests: load manifest JSON and assert consistency per member (prevent drift); assert member counts: `LogEvent=51`, `Spec=41`.
2. **Legacy Interfaces + toLegacyMatch / toLegacyShuffle**: `src/types.ts` defines minimal field sets for `IArenaMatch` / `IShuffleRound` / `IShuffleMatch` / `AtomicArenaCombat` / `ICombatUnit` / `CombatantInfo` / action types per spec Appendix A; `src/convert.ts`: `GladMatch → IArenaMatch` (unit kind / reaction / class mapped to manifest numeric values; numeric spec → spec-id string; `GladHpEvent → {effectiveAmount, amount, timestamp, spellId, spellName, logLine: {event, timestamp}, srcUnitId, destUnitId, …}`; units keyed by `unitId`; `dataType = 'ArenaMatch' | 'ShuffleRound'`; `durationInSeconds` derived). Tests: assert field-by-field conversion on synthetic `GladMatch` (reusing collect helper approach from `l3.compose` tests).
3. **WoWCombatLogParser Drop-in Entry**: `src/shim.ts` — `class WoWCombatLogParser(wowVersion, timezone?)`, `parseLine(line)`, events `'arena_match_ended'` (`IArenaMatch`) / `'solo_shuffle_ended'` (`IShuffleMatch`); internally wraps `GladLogParser + convert`. Tests: synthetic 3v3 line sequence → assert event payload fields.
4. **Differential Test Harness (resides in old fork `scratch/parser-diff/`, not in gladlog)**: `runOld.ts` (old package parse → normalized core facts JSON), `runNew.ts` (tsx imports gladlog compat → same-shape JSON), `diffCore.mjs` (compare: matches / rounds, bracket / zone, unit roster + spec + teamId + reaction, outcome, true death counts and timestamps, per-unit damage / heal `effectiveAmount` totals). Normalized ordering: units sorted by id, events aggregated into totals, timestamps in epoch ms. Run T0 fixtures + 20 real logs first, adjudicate divergences one-by-one (against raw logs), recorded in `scratch/parser-diff/adjudications.md`.
5. **buildMatchContext Structured Comparison (Differential Tier 2)**: Write `runContextDiff.ts` in old fork — for the same log, old parser output feeds directly into `buildMatchContext`; new output feeds into the same function via compat; compare returned structured context (prior to string concatenation), concurrent events stably sorted by `(timestamp, eventName, spellId, srcId)`. Pilot with T1 sample of 50 logs.
6. **T1 200-File Full Differential Testing + Report**: Stratified sampling manifest pinned; passing criterion = 0 unadjudicated differences; report committed to gladlog `docs/reports/`.

## Definition of Done

- All three compat tasks green; all divergences across T0 + T1 diff testing have adjudication conclusions; report landed in repo.
